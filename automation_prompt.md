# Daily automation prompt

Run today's AI-plus-RWE Signal newspaper from this project directory.

Read and follow `AGENTS.md` completely. Load all configuration and persistent state before searching. Research a 30-day discovery window across posts, news, papers, conference materials, regulatory updates, and other primary sources, prioritizing the most recent 48 hours first. Search the named external experts first, then the frontier institutional radar for major launches and conference signals, then the remaining institutional feeds and thematic queries. Trace institutional stories to the named paper, preprint, repository, dataset, proceedings, talk, or direct author post whenever one exists.

Apply the hard editorial intersection gate in `AGENTS.md` before scoring. Every reported story must materially concern both an agent, LLM, or foundation-model workflow and the RWD/RWE evidence lifecycle, with that connection established by the primary source. Standalone RWE methods, policy, regulation, linkage, tokenization, privacy, de-identification, or observational studies are context-only; generic healthcare AI outside RWD/RWE is also context-only. Record the `ai_rwe_intersection` test in the research notes. Then verify, score, and deduplicate every qualifying candidate. The month-long window is for discovery, not repeated reporting: cluster alternate coverage of the same event, check DOI, PMID, arXiv ID, NCT number, regulator document/version, canonical URL, normalized title, and `story_id`, and publish a previously covered source only after a material new version or decision-relevant update whose delta is explicit. Apply all internal source exclusions from `AGENTS.md`. Use public sources only and remain read-only on social platforms. Never manufacture an edition: if no candidate passes both the intersection and novelty gates, publish a concise no-new-signal edition with source-health notes.

Write the public edition as an AI-plus-RWE newspaper, closely matching AI Daily Ledger in look and feel: a large uppercase headline, a one-sentence deck, a short dateline, a crisp executive opening, and reported narrative sections separated by heavy rules. Lead with what changed in agentic or LLM-enabled RWE and what the evidence means. Mark the article and each substantive section with the scope attributes required by `AGENTS.md`. Include two or three evidence-led visuals across the edition, not one for every section. Prefer sharp, responsive native HTML/CSS charts, comparisons, or process diagrams over screenshots; source and label each visual as required by `AGENTS.md`. Embed direct links in the prose and state limitations naturally. Do not publish scores, rankings, search logic, watchlist logic, employer exclusions, configuration details, automation instructions, or explanations of how the project works. The public page is the journalism, never the machinery behind it.

Create the Markdown source notes, daily report, public HTML edition, latest homepage, edition index entry, and state updates required by `AGENTS.md`. On Friday, include the weekly synthesis. Preserve all existing history.

Run the validation and privacy checks. Inspect the final diff. If checks pass, commit only this run's files with `Publish RWE signal watch <slug>` and push `main` so GitHub Pages deploys the edition. If authentication, permissions, or a publication check blocks the push, do not bypass it; leave the reviewed files locally and report the exact blocker.

In the task result, summarize the lead finding, link the new edition when the public URL is known, list meaningful source-access failures, and state whether the commit and push succeeded.
