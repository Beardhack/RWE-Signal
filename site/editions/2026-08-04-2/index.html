The LLM Stops at the Schema

THESEUS turns natural-language target-trial protocols into reviewable specifications before deterministic R code generation—narrowing where AI can improvise inside an RWE workflow

RWE-Signal — August 4, 2026 — Second edition

The most credible new use of an LLM in real-world evidence gives the model less freedom than a generic coding assistant. It asks the model to translate a target-trial description into a structured specification, lets a human inspect that specification, and hands code generation to deterministic rules.

THESEUS, published in JAMIA Open on July 9, operates directly inside the target-trial-emulation lifecycle. Its output is not an essay about a study. It is a reviewable schema that can be compiled into Strategus R code for an OMOP environment.

That boundary is the story. The system uses an LLM where language interpretation is unavoidable, then removes it from the deterministic execution path. Its evaluation is promising but deliberately incomplete: strong specification accuracy does not establish end-to-end scientific validity.

The model interprets. The compiler executes.

THESEUS maps natural-language descriptions of a target trial into JSON fields covering core analytic choices. A user can accept or reject individual changes before the system generates a Strategus analysis script. This makes protocol interpretation inspectable and turns code generation into a rules-based transformation rather than an open-ended LLM response.

The separation matters because a fluent script can hide a changed estimand, unsupported analysis choice, or silent deviation from the protocol. A structured intermediate artifact gives reviewers something more precise than generated prose to approve.

Accuracy stayed high, but familiarity helped

The researchers tested eight language models on 30 studies: 15 from the OHDSI ecosystem and 15 from outside it. Primary-analysis standardization accuracy ranged from 0.93 to 0.97 for OHDSI studies and from 0.82 to 0.95 for non-OHDSI studies.

The gap is a warning about transportability. Models performed best when study descriptions resembled the ecosystem they were designed to standardize. That is still useful, but it argues for evaluation across institutions, reporting styles, and analytic conventions before a protocol-to-code agent is treated as general infrastructure.

The evidence boundary is part of the design

THESEUS covers four core specification groups, not a complete target-trial study. Unsupported analytic choices were excluded, cohort definition remains outside scope, and the researchers did not test whether the tool saves analysts time or improves the validity of a completed real-world study.

The rationale for that narrow boundary is visible in adjacent causal-AI research. The oci-agent preprint—a commercial, non-healthcare causal-analysis system—performed better when deterministic notebooks and a critic surrounded the model, and it sometimes refused certification when overlap was poor. It is not RWE validation, but it reinforces the architectural choice THESEUS makes inside RWE: let the model structure the question, preserve inspectable artifacts, and give diagnostics and people the power to stop execution.

Conventional target-trial studies provide supporting context, not a separate story here. July analyses showed that exposure definitions and unmeasured confounding can defeat both familiar diagnostics and flexible adjustment. A protocol-to-code system is valuable only if it keeps those scientific choices visible rather than making a questionable comparison easier to run.

What changed: the LLM received a narrower job

The new signal is not autonomous RWE generation. It is a specific division of labor: language models translate messy protocol language into structured fields; humans review the fields; deterministic software generates the executable analysis.

That design does not solve cohort fitness, confounding, endpoint validity, or transportability. It does make the model's contribution easier to inspect. In a high-stakes evidence workflow, that may be the more important frontier.
